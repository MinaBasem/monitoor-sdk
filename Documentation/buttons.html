Button Tracking

The fastest way to count button presses. Add a single modifier or swap one class — no changes to your existing action logic required.

SwiftUI — .monitoorTap()

Add .monitoorTap("event_name") to any tappable SwiftUI view. It fires a simultaneousGesture alongside the view's own tap action, so your existing logic is completely unaffected.

Basic usage

Button("Subscribe") {
    startSubscription()
}
.monitoorTap("subscribe_tapped")

With properties

Button("Buy Premium") {
    purchase()
}
.monitoorTap("buy_premium_tapped", properties: [
    "plan":   "annual",
    "price":  49.99
])

On destructive buttons

Button("Delete Account", role: .destructive) {
    deleteAccount()
}
.monitoorTap("delete_account_tapped", properties: ["source": "settings"])

On buttons inside a List / ForEach

ForEach(playlists) { playlist in
    Button { play(playlist) } label: {
        PlaylistRow(playlist: playlist)
    }
    .monitoorTap("playlist_played", properties: [
        "name": playlist.name,
        "track_count": playlist.tracks.count
    ])
}

On non-Button tappable views

.monitoorTap() works on any view, not just Button. Attach it after .onTapGesture:

// Image tap
Image(systemName: "heart")
    .onTapGesture { toggleLike() }
    .monitoorTap("post_liked")

// Card tap
NowPlayingCard(track: track)
    .onTapGesture { openNowPlaying() }
    .monitoorTap("now_playing_opened", properties: ["source": "hero_card"])

// NavigationLink
NavigationLink(value: playlist.id) {
    PlaylistTile(playlist: playlist)
}
.monitoorTap("playlist_opened", properties: ["name": playlist.name])

On tab bar items

ForEach(tabs, id: \.label) { tab in
    Button {
        selectedTab = tab
    } label: {
        TabItemView(tab: tab, isActive: selectedTab == tab)
    }
    .monitoorTap("tab_switched", properties: ["tab": tab.label.lowercased()])
}

Conditional tracking

// Track liked vs unliked state at the moment of the tap
Button { toggleLike(track) } label: {
    Image(systemName: liked ? "heart.fill" : "heart")
}
.monitoorTap(liked ? "track_unliked" : "track_liked")

UIKit — MonitoorButton subclass

A drop-in replacement for UIButton. Tracks every .touchUpInside automatically.

Programmatic creation

let buyButton = MonitoorButton(
    eventName: "buy_premium_tapped"
)

let deleteButton = MonitoorButton(
    eventName: "delete_account_tapped",
    properties: ["source": "profile_screen"]
)

Changing the event name at runtime

let playButton = MonitoorButton(eventName: "track_played")

// Update when the playing state changes
playButton.trackingEventName   = isPlaying ? "track_paused" : "track_played"
playButton.trackingProperties  = ["title": currentTrack.title]

In Interface Builder / Storyboards

In the Identity Inspector, change the button's class from UIButton to MonitoorButton. Then set trackingEventName in viewDidLoad:

@IBOutlet weak var subscribeButton: MonitoorButton!

override func viewDidLoad() {
    super.viewDidLoad()
    subscribeButton.trackingEventName  = "subscribe_tapped"
    subscribeButton.trackingProperties = ["plan": currentPlan]
}

UIKit — .monitoor_trackTaps() extension

Use this when you can't change the button's class — for example, buttons in third-party views or system-provided controls.

// Attach tracking to any existing UIButton in viewDidLoad
override func viewDidLoad() {
    super.viewDidLoad()

    signInButton.monitoor_trackTaps(eventName: "sign_in_tapped")

    shareButton.monitoor_trackTaps(
        eventName: "share_tapped",
        properties: ["screen": "profile"]
    )
}
ℹ️
The tracker object created by monitoor_trackTaps() is stored as an associated object on the button and is released automatically when the button is deallocated. You don't need to keep a reference to it.

Choosing the right approach

SituationRecommended approach
SwiftUI Button, NavigationLink, or any tappable view.monitoorTap() modifier
New UIKit button, programmaticMonitoorButton subclass
Existing UIKit button, can change classMonitoorButton in Identity Inspector
UIKit button you cannot subclass.monitoor_trackTaps() extension
Button inside a 3rd-party component.monitoor_trackTaps() or Monitoor.track() in the action
