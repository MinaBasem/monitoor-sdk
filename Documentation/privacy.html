Privacy

The SDK is designed to be privacy-first by default. No PII is collected unless you explicitly opt in, and even then it is hashed before leaving the device.

iOS version✅ Yese.g. iOS 18.0

User ID hashing

If you call Monitoor.identify(userId:), the provided string is SHA-256 hashed on-device before it is stored or transmitted. The hash is a one-way function — neither Monitoor nor the ingest server can reverse it to obtain the original ID.

// What you pass:
Monitoor.identify(userId: "user-12345")

// What is sent in the event:
// "user_id_hash": "592a3b8f3ea3c..."  (SHA-256 hex)
// "user-12345" never leaves the device in plaintext

App Store privacy manifest

The SDK does not require any entries in your app's PrivacyInfo.xcprivacy file. It does not use any of the APIs listed under NSPrivacyAccessedAPITypes.

App Tracking Transparency

The SDK never accesses ASIdentifierManager or any advertising identifier. Your app does not need to request ATT permission to use MonitoorSDK.

Consent & opt-out

For consent-driven apps, you can stop all collection at runtime. The choice is persisted across launches.

// Stop all capture + transmission, and purge any buffered events
Monitoor.optOut()

// Resume collection later
Monitoor.optIn()

// Wire to a consent banner
func onConsentChanged(granted: Bool) {
    granted ? Monitoor.optIn() : Monitoor.optOut()
}

When opted out: no events are captured (including system events), nothing is transmitted, and the local buffer is emptied. The opt-out persists across relaunches until optIn() is called.

ℹ️
Opt-out controls collection on the device. To delete data already stored server-side, use the GDPR deletion query below.

GDPR — data deletion

To delete all data associated with a device under a right-to-erasure request, run the following against your Neon database:

-- Delete all events for a specific device
DELETE FROM "Event"
WHERE "deviceId" = 'the-device-uuid'
    AND "apiKeyId" = 'your-api-key-id';

Because device_id is not linked to any Apple identifier or real-world identity, this satisfies GDPR deletion requirements without needing to know who the user is.

Children's privacy (COPPA)

The SDK collects no information that would classify as personal information for children under COPPA. It does not collect name, address, email, phone number, geolocation, or photo. If your app targets children, you can use MonitoorSDK without triggering COPPA-specific restrictions.
