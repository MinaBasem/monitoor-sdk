Tracking

Sessions

A session is a continuous period of app use. The SDK tracks session start, duration, and end automatically — no setup required.

Session lifecycle

A session begins when the app opens and ends after a configurable period of inactivity in the background (default: 30 minutes).

User opens app
  → $app_open event
  → new session UUID generated
  → session timer starts

User uses the app...

User backgrounds the app
  → $app_background event (with $session_duration_s)

If user returns within 30 minutes:
  → session continues, no new $app_open

If user returns after 30+ minutes:
  → $app_open event (new session UUID)
  → session timer resets

Reading session duration

The current elapsed session time (in seconds) is available at any point:

let seconds: TimeInterval = Monitoor.sessionDuration
// e.g. 142.7

// Format for display
let minutes = Int(Monitoor.sessionDuration / 60)
// e.g. 2 (minutes)

Use in your own events

// Attach session duration to a custom event
Monitoor.track("paywall_shown", properties: [
    "session_duration_s": Monitoor.sessionDuration,
    "trigger": "feature_gate"
])

Session duration in $app_background

Every time the app backgrounds, the SDK automatically sends a $app_background event with the full session duration attached:

// Event sent automatically by the SDK on background:
{
  "name": "$app_background",
  "properties": {
    "$session_duration_s": 247.3
  }
}

You can query average session duration in SQL:

SELECT
    AVG((properties->>'$session_duration_s')::float) AS avg_session_seconds,
    COUNT(*) AS total_sessions
FROM "Event"
WHERE name = '$app_background'
    AND "occurredAt" > NOW() - INTERVAL '30 days';

Session ID

Every event carries a session_id UUID, which is the same for all events within a single session. This lets you reconstruct the exact sequence of events within a session:

SELECT name, "occurredAt", properties
FROM "Event"
WHERE "sessionId" = 'your-session-uuid'
ORDER BY "occurredAt";

Configuring session timeout

Change how long the app must be in the background before a new session is started:

Monitoor.configure(
    apiKey: "mn_live_...",
    options: MonitoorOptions(
        sessionTimeout: 15 * 60  // 15 minutes
    )
)

Forcing a new session

Calling Monitoor.reset() immediately starts a new session and clears the user identity. Use this on sign-out:

func signOut() {
    auth.logout()
    Monitoor.reset()  // new session + new anonymous device ID
}
