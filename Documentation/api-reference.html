API Reference

Complete reference for every public method, property, type, and modifier in MonitoorSDK v1.0.0.

Monitoor

The SDK's public interface. All members are static. Thread-safe. Safe to call from any queue or thread.

static func configure(apiKey: String, options: MonitoorOptions)

Initialises the SDK. Must be called once before any other method. Subsequent calls are silently ignored.

  • apiKeyStringYour Monitoor API key. Must start with mn_live_ for production or mn_dev_ for development.
  • optionsMonitoorOptionsConfiguration. All fields have defaults — pass MonitoorOptions() to use them all.
static func track(_ name: String, properties: [String: Any])

Records a named event. Writes to the local buffer synchronously before returning. Thread-safe.

  • nameStringEvent name. Use snake_case. Avoid the $ prefix (reserved for system events).
  • properties[String: Any]Optional key-value pairs. Values must be String, Int, Double, or Bool. Defaults to empty.
static func screen(_ name: String, properties: [String: Any])

Records a $screen_view event with a $screen_name property. Prefer .monitoorScreen() modifier in SwiftUI.

  • nameStringThe screen name as it should appear in the dashboard.
  • properties[String: Any]Optional additional properties merged with $screen_name.
static func startTimer(_ name: String)

Starts a named timer. When track(name:) is called with the same name, the elapsed duration is automatically attached as $duration (seconds as Double).

  • nameStringThe timer key. Must exactly match the event name passed to track().
static func identify(userId: String)

Associates subsequent events with a user. The provided ID is SHA-256 hashed on-device before storage or transmission. Call after sign-in.

  • userIdStringYour internal user identifier. Do not pass PII (email, phone, name).
static func setUserProperties(_ properties: [String: Any])

Attaches non-PII attributes to the current user. Properties are merged — keys overwrite each other on conflict.

  • properties[String: Any]Key-value pairs describing the user. Values must be String, Int, Double, or Bool.
static func reset()

Clears the user identity and user properties, generates a new anonymous device ID, and starts a new session. Call on sign-out.

static func trackRevenue(productId: String, amount: Double, currency: String, type: RevenueType, transactionId: String)

Manually records a revenue event. Use for StoreKit 1 or non-StoreKit purchases. StoreKit 2 is captured automatically.

  • productIdStringProduct identifier from your payment provider or App Store Connect.
  • amountDoublePurchase amount as a decimal number.
  • currencyStringISO 4217 currency code, e.g. "USD", "EUR".
  • typeRevenueType.subscription, .oneTime, or .consumable.
  • transactionIdStringUnique transaction identifier for deduplication.
static var sessionDuration: TimeInterval

The elapsed time in seconds since the current session started. Returns 0 if the SDK is not configured. Read-only.

static func flush(completion: (() -> Void)?)

Forces an immediate flush of all buffered events. The completion closure is called when the buffer is drained or a non-retryable error occurs.

  • completion(() -> Void)?Optional closure called on completion. Not guaranteed to be called on the main thread. Defaults to nil.

SwiftUI View Modifiers

modifier .monitoorTap(_ eventName: String, properties: [String: Any])

Tracks a tap on the modified view as a Monitoor event. Uses simultaneousGesture — fires alongside the view's own tap action without interfering with it. Applicable to any View.

  • eventNameStringThe event name sent to Monitoor.
  • properties[String: Any]Optional properties. Defaults to empty.
modifier .monitoorScreen(_ name: String, properties: [String: Any])

Sends a $screen_view event when the view appears (.onAppear). Use on screen-level SwiftUI views.

  • nameStringScreen name as it should appear in the dashboard.
  • properties[String: Any]Optional additional properties. Defaults to empty.

UIKit

class MonitoorButton: UIButton

A UIButton subclass that automatically tracks every .touchUpInside event.

  • trackingEventNameStringThe event name to send on tap. Can be changed at runtime.
  • trackingProperties[String: Any]Properties sent with each tap event. Defaults to empty.
let btn = MonitoorButton(eventName: "subscribe_tapped")
let btn2 = MonitoorButton(eventName: "buy_tapped", properties: ["plan": "annual"])
extension UIButton .monitoor_trackTaps(eventName: String, properties: [String: Any])

Attaches tap tracking to any existing UIButton without subclassing. The tracker is retained as an associated object and released when the button is deallocated.

  • eventNameStringThe event name to send on tap.
  • properties[String: Any]Properties sent with each tap event. Defaults to empty.
