Revenue Tracking

Track purchases and subscriptions to measure your app's revenue. StoreKit 2 transactions are captured automatically. StoreKit 1 and any non-StoreKit payments are tracked with a single manual call.

StoreKit 2 — automatic

When captureRevenue: true (the default), the SDK subscribes to Transaction.updates at startup. Every verified transaction is captured automatically — no additional code required.

// This is handled automatically by the SDK.
// No code required in your app for StoreKit 2.
Monitoor.configure(
    apiKey: "mn_live_...",
    options: MonitoorOptions(
        captureRevenue: true  // default — StoreKit 2 auto-capture active
    )
)

Each captured transaction produces a $revenue event with these properties:

PropertyTypeExample
product_idStringcom.example.premium_annual
typeStringsubscription, one_time, consumable
transaction_idString2000000123456789
amountDouble49.99
currencyStringUSD
ℹ️
Deduplication. Every revenue event carries a transaction_id. Duplicate transmissions of the same transaction are silently dropped by the ingest service via ON CONFLICT DO NOTHING.

StoreKit 1 — manual

Call Monitoor.trackRevenue() inside your SKPaymentTransactionObserver after a successful transaction:

extension StoreManager: SKPaymentTransactionObserver {

    func paymentQueue(
        _ queue: SKPaymentQueue,
        updatedTransactions transactions: [SKPaymentTransaction]
    ) {
        for transaction in transactions {
            switch transaction.transactionState {
            case .purchased:
                Monitoor.trackRevenue(
                    productId:     transaction.payment.productIdentifier,
                    amount:        product.price.doubleValue,
                    currency:      Locale.current.currency?.identifier ?? "USD",
                    type:          .subscription,
                    transactionId: transaction.transactionIdentifier ?? ""
                )
                queue.finishTransaction(transaction)
            default:
                break
            }
        }
    }
}

Non-StoreKit purchases

For payments processed outside StoreKit (web purchases, server-side billing, etc.), call trackRevenue() with your own identifiers:

// After a successful server-side payment
func onPaymentConfirmed(receipt: PaymentReceipt) {
    Monitoor.trackRevenue(
        productId:     receipt.productId,
        amount:        receipt.amount,
        currency:      receipt.currency,
        type:          .subscription,
        transactionId: receipt.id
    )
}

RevenueType values

ValueUse for
.subscriptionAuto-renewable subscriptions (monthly, annual)
.oneTimeNon-consumable one-time purchases (premium unlock, lifetime access)
.consumableConsumable items (credits, coins, tokens)

Querying revenue data

-- Total revenue by product in the last 30 days
SELECT
    properties->>'product_id'   AS product,
    properties->>'currency'     AS currency,
    COUNT(*)                       AS transactions,
    SUM((properties->>'amount')::float) AS total
FROM "Event"
WHERE
    name = '$revenue'
    AND "occurredAt" > NOW() - INTERVAL '30 days'
GROUP BY product, currency
ORDER BY total DESC;
